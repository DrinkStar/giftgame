# SeaAnomaly 数值平衡初稿（Iter10 · 定稿 §12 待定项第一版）

> 状态：初稿。记录当前实际数值 + 校准建议。任何数值改动必须同步更新此表与相关测试（`test/src/EnemyDataTest.cs` 等锁定部分数值）。
> 校准建议仅作记录，本轮**未强制修改**（避免破坏已锁测试与教程节奏）；需人工窗口实测后决定是否落地。

## 1. 玩家基础（src/player/PlayerStats.cs）

| 指标 | 值 | 说明 |
|---|---|---|
| MaxHealth | 100 | 敌方单次伤害对照基准 |
| MaxHunger / MaxThirst | 100 / 100 | 消耗速率见下 |
| HungerDecreaseRate | 1/30 每秒 | 满值 → 0 需 50 分钟 |
| ThirstDecreaseRate | 1/20 每秒 | 满值 → 0 需 33 分钟 |
| DamageFromNoHunger / NoThirst | 2 / 3 每秒 | 空值持续掉血 |

| JumpStaminaCost | 10 | |

**日长 25 分钟（T8.3）** → 每游戏日饥饿约 -50%、口渴约 -75%。出生补给（浆果×3、椰子等）约支撑前 1-2 日。建议：教程期（前 15 分钟）前无需进食，节奏合理。
